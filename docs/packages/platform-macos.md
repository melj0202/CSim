# Illumo macOS scaffold

macOS is not supported. Engine-owned `Main.cpp`, `MacSaveLoad.mm`, and
unselected `CocoaRenderWindow.*` remain unverified scaffolding. A future port
must validate Objective-C++, the GLFW OpenGL profile, AppleClang builds, tests,
Retina rendering/input, Cocoa dialogs, and clean shutdown before support is
claimed.
